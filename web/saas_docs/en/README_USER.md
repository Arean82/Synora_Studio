# SaaS Portal: End User Guide

Welcome to the Synora Web Interface! This platform allows you to harness powerful AI models without installing any software on your computer.

## Quick Start
1. Create an account and log in.
2. Navigate to your **Settings** and securely provide your preferred AI Provider Key (OpenAI, Gemini, Anthropic, etc).
3. Open the Chat Interface and begin generating text, code, or analyzing documents via RAG.

Because your data is housed in an isolated SQLite database, your chat history and API keys are completely invisible to the platform administrators and other tenants.
